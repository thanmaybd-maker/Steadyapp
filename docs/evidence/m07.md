# M07: Privacy and Recovery

## 1. Description
Implemented the Privacy and Recovery milestone, which provides data export and backup functionalities while adhering to strict privacy requirements.

## 2. Evidence of Implementation
- Created `ExportPolicy.kt` for generating standard Markdown logs of Daily Plans and Weekly Reviews.
- Safety plan data is strictly omitted from the Markdown export.
- Created `BackupService.kt` to handle encrypted JSON backups of the room database (excluding safety plans and sensitive device settings).
- Created `DocumentAdapter.kt` wrapping SAF (Storage Access Framework) to handle writing to user-selected URIs.
- Developed `SettingsViewModel` and `SettingsScreen` providing toggles for sensitive export data, buttons to perform exports/backups, and a "Danger Zone" to securely wipe all local data from the database.
- Wired `SettingsScreen` and `DocumentAdapter` into `AppContainer.kt` and `SteadyAppNavigation.kt`.
