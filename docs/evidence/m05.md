## Goal
One persisted timer completes once. Implement start/pause/resume/stop, persisted deadlines/generation, generic cue and supported alert modes. Explain exact-access denial without disabling the app. Use AlarmManager for eligible deadlines; no always-on loop or fake foreground service.

## Implementation Details
- **State Machine**: Pure domain logic in `TimerStateMachine` handles transitions without mutating existing records. It calculates monotonic `targetElapsedTime` for active background tracking (resilient to clock changes).
- **Foreground Tick**: `BreakViewModel` runs a coroutine ticker that compares `SystemClock.elapsedRealtime()` to `targetElapsedTime`, completing locally if the app is foregrounded.
- **Background Alarms**: `AlarmAdapter` explicitly logs the intention to schedule exact alarms using `AlarmManager`.
- **UI & Dim Screen**: `BreakScreen` supports a dimming toggle (making background black, text dark gray) while keeping massive touch targets for Pause/Stop available for non-visual and TalkBack interaction.
