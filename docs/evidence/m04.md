# Milestone 4 Evidence

## Goal
Reach support offline. Create empty optional local fields and manually entered contacts. Compile verified public numbers and verification date. Global help works even if the encrypted database cannot be opened.

## Packages Changed
- `domain`: `SafetyModels.kt` (SafetyPlan, SupportContact, PublicHelp)
- `data`: `SafetyEntity.kt`, `SafetyDao.kt`, updated `SteadyDatabase.kt`
- `platform`: `DialerAdapter.kt`
- `ui`: `SafetyViewModel.kt`, `SafetyScreen.kt`, updated `SteadyAppNavigation.kt`

## Implementation Details
- **Public Help**: Public numbers (Tele-MANAS, Emergency 112) are hardcoded into `PublicHelp` object.
- **Dialer Integration**: `DialerAdapter` creates an `Intent.ACTION_DIAL` to launch the phone's dialer, matching the "No CALL_PHONE" requirement.
- **Safety Database**: `SafetyPlanEntity` and `SupportContactEntity` are managed using `SafetyDao` and protected inside the existing `SteadyDatabase` (SQLCipher).
- **SafetyScreen**: A separate Compose screen presenting public help numbers clearly at the top (with a distinct background color) and the personal plan fields below. If the encrypted DB fails to open, public numbers remain fully accessible.
- **Navigation**: Integrated `SafetyViewModel` into `SteadyAppNavigation.kt`.
