# Milestone 2 Evidence

## Goal
Save one synthetic plan privately. Implement the schema and encrypted storage boundary, with non-personal bootstrap DataStore only. Generate/wrap the database secret, open encrypted Room and commit one record.

## Packages Changed
- `domain`: `DailyPlan.kt`, `DayMode` enum.
- `data`: `SteadyDatabase.kt`, `DailyPlanEntity.kt`, `DailyPlanDao.kt`, `Converters.kt`
- `platform`: `DatabaseKeyManager.kt`
- `di`: `AppContainer.kt`
- `ui`: `DiagnosticViewModel.kt`, updated `MainActivity.kt` to run diagnostics.
- `app/build.gradle.kts`: Added `room-runtime`, `room-ktx`, `room-compiler` (KSP), `android-database-sqlcipher`.

## Implementation Details
- **Schema**: Room database configured with `exportSchema = true` and entity `DailyPlanEntity`.
- **Encryption**: `DatabaseKeyManager` generates a random 256-bit AES secret, encrypts it using Android Keystore `AES/GCM/NoPadding`, and saves the encrypted secret and IV to private files (`db_secret.enc`, `db_secret_iv.enc`). `AppContainer` unwraps the secret and provides it to `SupportFactory(passphrase)` to initialize SQLCipher.
- **Diagnostics**: Modified `MainActivity` to inject the DB via `DiagnosticViewModel`, write a canary record containing `"CANARY_PLAINTEXT_SECRET"`, and retrieve it.
