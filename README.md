# Steady

**A private, accessible daily workspace.**

Steady helps you manage daily priorities, breaks, and personal reflection without the pressure of streaks, overdue tasks, or visual clutter. It is built entirely offline, keeps your data encrypted locally, and is optimized for accessibility (including TalkBack support and large touch targets).

## Features
- **Today**: Set your day's priorities (Study, Build, Health) and minimal goals.
- **Break Timer**: Non-visual, haptic-supported break timers for focus sessions.
- **Safety**: An offline, encrypted safety plan and immediate access to public emergency contacts.
- **Review**: A factual weekly reflection tool to help adjust habits.
- **Settings**: Complete control over your data, including markdown export, encrypted backups, and a secure local wipe.

## Privacy
- No internet permissions are required or requested.
- Data is stored in an encrypted Room database.
- Safety plan information is never included in standard Markdown exports.

## Building and Installation
Steady is a standard Android project using Jetpack Compose and Room.
To build:
1. Open the project in Android Studio.
2. Build the signed APK.
3. Transfer and install on your device.

*Note: The current iteration focuses on source code completion and milestone verification. Actual device building requires an authorized host environment.*
