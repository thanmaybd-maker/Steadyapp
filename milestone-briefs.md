# Milestone Briefs

## Milestone 1: prove the scaffold
**Goal**: one accessible app shell. Generate a reproducible native project, choose and prove compatible dependencies, and open the five labelled destinations. Use only synthetic data. Add global public-help access and neutral shell text; do not implement private records yet.

## Milestone 2: encrypted repository
**Goal**: save one synthetic plan privately. Implement the schema and encrypted storage boundary, with non-personal bootstrap DataStore only. Generate/wrap the database secret, open encrypted Room and commit one record.

## Milestone 3: Today and minimum day
**Goal**: retrieve one small daily plan. Add three priorities, next action, minimum day, evidence, shutdown and one-tap pause. Use encrypted repository flow and logical-day snapshots. Add the small Food ideas reference.

## Milestone 4: local Safety route
**Goal**: reach support offline. Create empty optional local fields and manually entered contacts using the structured plan above. Compile verified public numbers and verification date.

## Milestone 5: non-visual Break
**Goal**: one persisted timer completes once. Implement start/pause/resume/stop, persisted deadlines/generation, generic cue and supported alert modes.

## Milestone 6: sparse weekly review
**Goal**: review one imperfect week. Select an ending day and display the previous seven logical days. Let the user enter five optional indicators and four questions. Show recorded evidence.

## Milestone 7: privacy and recovery
**Goal**: control and recover eligible data. lock/recents; Markdown preview/export; authenticated eligible-data backup/import; confirmed local deletion.

## Milestone 8: installation readiness
**Goal**: a reviewable personal-use APK. Defect fixes for stated criteria, README/build instructions, signing/version configuration, release checklist and final evidence. No new feature.
